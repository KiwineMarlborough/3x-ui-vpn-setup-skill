# Инструкция: свой VPN за вечер с помощью ИИ

> **Если тебя достали блокировки чужих VPN-сервисов** — подними **личный** сервер. Этот skill учит ИИ-агента делать всё сам: от чистого VPS до рабочей подписки в Happ, а затем защищать сервер, проверять его и чинить.
>
> **Твоя роль:** купить VPS, привязать домен, дать агенту SSH — и забрать готовые ссылки. **Не** нужно вручную править Xray, SQLite и nginx.

## Шаг 0. Что подготовить (15–30 минут, один раз)

| Что | Пример | Зачем |
|-----|--------|-------|
| VPS Ubuntu 22/24/26 | 1 GB RAM, DE/NL | Сервер VPN |
| IP адрес | `203.0.113.10` | A-запись DNS |
| Домен CDN/VPN | `cdn.mydomain.com` | VPN + подписка + сайт-маска. **Единственное публичное имя** |
| **Твой публичный IP** | `198.51.100.7` | Белый список защиты: иначе можно заблокировать самого себя |
| SSH-ключ | `~/.ssh/vps_ed25519` | Вход без пароля |
| Sudo | отдельная учётка агента, `NOPASSWD`, только по ключу | Агент ставит пакеты |

**DNS:** одна A-запись `cdn` → IP VPS. В Cloudflare — **серое облако** (прокси выкл): оранжевое ломает порты VPN (`dns-setup.md`).
**Записи для панели не нужно** — панель закрыта от интернета и открывается через SSH-туннель.
Имя выбирай нейтральное (`cdn`, `static`) — не `vpn`/`panel`: оно навсегда попадёт в публичные журналы сертификатов.

**Reality SNI:** любой чужой живой HTTPS-сайт (TLS 1.3), например `pixelforge.pics` — не свой VPN-домен; на каждый Reality-порт свой. Skill проверит.

### Как безопасно дать доступ

Лучшие варианты (по убыванию):

1. **Отдельный пользователь агента** + **SSH-ключ** (пара создаётся на машине агента, тебе отдаётся только публичная часть) + `sudo NOPASSWD` + **срок действия** (`chage -E`). Команды — в `agent-access-hygiene.md`.
2. Временный sudo-пароль на ≤ 30 дней — потом сменить.
3. Root по паролю **не** давай.

После работы: удалить учётку агента, убрать её sudo-правило, ротировать секреты, которые он видел.

## Шаг 3. Что агент сделает сам

1. Обновит систему, настроит UFW
2. Включит Fail2Ban и IPsum (≈17 тыс. известных вредоносных IP отбрасываются сразу; твои IP — в белом списке; пять минут на откат, если что-то не так)
3. Установит 3X-UI, закроет порт панели
4. Выпустит сертификат на CDN-имя, поднимет nginx с «CDN»-страницей на 443
5. **Переключит продление сертификата на webroot** и проверит его на тестовом сервере Let's Encrypt (иначе сертификат тихо истечёт через ~90 дней)
6. Создаст inbound'ы (Reality, TCP, XHTTP, Hysteria) и, если нужно, AmneziaWG
7. Настроит кастомные пути подписки и таблицу `hosts` (от неё зависят ссылки)
8. Включит Happ routing (.ru напрямую)
9. Прогонит `loopback-test.py` (настоящий хендшейк по каждому профилю) и `verify-server.sh`
10. Отдаст **subscription URL**, инструкцию доступа к панели и список того, что сделано

## Шаг 4. Телефон (Happ Plus)

1. Скопировать subscription URL из handoff
2. Happ → добавить подписку
3. Потянуть вниз для обновления routing
4. Подключиться к профилю **Reality** (основной)

> Если профиль показывает **«n/a»** — это ещё не поломка: индикатор в клиентах ненадёжен. Проверяй реальный трафик, потом другой клиент, потом другую сеть (`testing-methods.md`).
> **AmneziaWG** не входит в подписку Happ: для него приложения AmneziaVPN/AmneziaWG и файл `.conf`/QR.

## Как открыть админ-панель

Панель **закрыта от интернета** (так надёжнее и её не найдут сканеры):

1. В `hosts` на своём ПК: `127.0.0.1 <имя-панели>` (Windows: `C:\Windows\System32\drivers\etc\hosts`, от администратора).
2. Туннель (окно держать открытым): `ssh -i <ключ> -L 29800:127.0.0.1:29800 <user>@<ip-vps>`
   (MobaXterm: Tunneling → New SSH tunnel → Local port forwarding: порт 29800, remote `127.0.0.1:29800`, SSH server `<ip-vps>:22`).
3. Браузер: `https://<имя-панели>:29800/<webBasePath>/`, принять предупреждение о самоподписанном сертификате.
   `localhost` или IP дают 403 — это защита. Подробности: `panel-tunnel-access.md`.

## Если что-то сломалось

**Не переустанавливай сервер сразу и не откатывай серверные настройки наугад** — дай агенту repair-промпт:

```text
Skill 3x-ui-vpn-setup. Следуй references/repair-only.md.
Симптом: <одной строкой>.
Сначала audit-server.sh, check-cert-expiry.sh, loopback-test.py. Не переустанавливай.
Не откатывай серверные изменения, пока серверная сторона не доказана (testing-methods.md).
```

| Симптом | Куда смотреть |
|---------|---------------|
| Reality работает, остальные профили и подписка мертвы | **Истёк сертификат** — `check-cert-expiry.sh`, `cert-renewal-nginx.md` |
| Профиль «n/a» в клиенте | `loopback-test.py` → другой клиент → другая сеть |
| Нет доступа только из одной сети | Ложное срабатывание IPsum — белый список (`blocklist-ipsum-fail2ban.md`) |
| JSON sub 500 | Hysteria — `fix-hysteria-stream.py` |
| Sub 404 | Обрезанный sub_id или пути — `set-sub-paths.py` |
| В ссылках неверные `security`/`sni` | Устаревшая строка таблицы `hosts` (`gotchas.md`) |
| Podkop не коннектит | `fix-podkop-flow.py`, фактический flow (`inbounds.md`) |
| Панель не открывается | Туннель + hosts; 403 по IP — норма (`panel-tunnel-access.md`) |
| Всё мертво | `audit-server.sh` → `repair-only.md` |

## FAQ

**Нужно ли уметь Linux?**  
Нет — если агент с SSH. Базово: купить VPS, прописать DNS, вставить промпт.

**Можно без домена?**  
Технически да, но skill рассчитан на домен + TLS + CDN fallback. С доменом стабильнее и незаметнее.

**Почему панель недоступна из интернета?**  
Публичное имя панели и сертификат для неё навсегда попадают в публичные журналы сертификатов, а страницу входа находят интернет-сканеры независимо от секретного пути. Закрытый порт нельзя ни подобрать, ни проэксплуатировать. Заходишь через SSH-туннель.

**Что делает IPsum и не заблокирует ли он меня?**  
Отбрасывает адреса, которые уже числятся минимум в трёх независимых чёрных списках. Твои IP — в белом списке и проверяются до включения; есть автооткат на 5 минут. Единственный риск — редкий адрес мобильного оператора в списке: тогда доступ пропадает из одной сети, лечится добавлением в белый список.

**Сертификат продлится сам?**  
Да, если выполнен шаг с `deploy-acme-renewal.sh` (webroot-режим). Стандартный режим acme.sh из 3X-UI с nginx на порту 80 **не** продлевается.

**Это легально?**  
Skill — инструмент настройки. Соблюдай законы своей страны и TOS хостинга.

**Агент увидит мои пароли?**  
Да, если вставишь в чат. Лучше: ключ SSH + отдельная учётка агента с датой окончания, после setup — ротация. См. `secrets-management.md`, `agent-access-hygiene.md`.
